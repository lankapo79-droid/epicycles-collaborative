# Epicycles Collaborative Playground

Real-time collaborative Fourier epicycles drawing toy.

A challenging interactive visualization where multiple users can draw and see spinning circles trace beautiful shapes together.

## Features (planned)
- Interactive canvas drawing
- Fourier series epicycles animation
- Multi-user real-time sync (via polling or WebSockets)
- Shareable sessions
- Smooth 60fps performance

Built as a challenge for Grok/Aina.

Deployed on Vercel and Netlify.
